## SQLite canonical / MD derived

- **Canonical:** `.repograph/db.sqlite` — structure, issues, labels, change staging, semantic embeddings.
- **Config:** `.repograph/repograph.yaml` — ignore/sensitive globs, semantic settings (applied via **`config apply`**).
- **Derived:** `.repograph/repograph.md` — regenerated by **`export`**; safe to re-read, unsafe to hand-edit as source of truth.

Never grep-the-tree for inventory when **`export`** or **`semantic query`** can answer the question.
